# 七个回访区域的体量与联通复核

七区共有 22 个普通流程可达的区域地点、22 个区域状态。规则使用 23 份不同的实际场景，其中 9 份是可横向滚动的长地图。外哨前庭旧档入口复用绝宫外庭的地形；凤溪西岸复航后切到尾声地图。这些场景沿用十章与潮关已有的地形，回访增加的是任务、NPC、战斗、阶段变化和可走的路。 [场景与点位日志](regional-geometry.log)

| 区域 | 常规地点 / 状态 | 普通回访实战 | 能在场内核对的结果 |
| --- | ---: | --- | --- |
| 凤溪渡口 | 3 / 3 | 0 | 署名或密封决定证词如何交接。验药开放双向后渡，两条任务可交换调查顺序。 |
| 拜剑山庄 | 2 / 3 | 1 | 击退扣铁守卫后修通运铁绞梯。工匠接单与收留匠户改变修具台或药柜，也改变外哨入口。 |
| 天下会外哨 | 2 / 3 | 1 | 执事与东瀛巡山人在不同阶段守灯轮。修好灯线开放巡灯吊篮。具名和匿名抄件有不同后效。 |
| 生死门 | 2 / 3 | 0 | 护脉散或换气诀分别影响绝无神开场。修好升担架可双向往返断栈东坡。 |
| 无神绝宫 | 4 / 3 | 1 | 火后主廊失效，仍可经西闸补证；准备充分可用侧门撤离并选择救伤者或护送证人。击退火后巡卫再开水道便路。 |
| 凌云山 | 6 / 3 | 2 | 西坡安置、护药和断后都能推进终战准备。开石道、护持聂风和拦截追兵分别生效，补救可在战后登记。 |
| 潮关 | 3 / 4 | 2 | 七个来源可作独立证据。公开分粮与州府押卷有不同互动、回执和商铺。漏救阿芦可从战后粮仓补救。 |

七个区域模块有 16 条任务记录，其中三条用于分别记录同一组凌云山撤离选择。区域任务与活动共用 74 个可保存的证据或结案键。区域之间另有五条实际交接，涉及角色、战斗开场、药品或实体通路。表中 7 个回访战斗按互动入口计数，包含同一任务的替代战斗与有支援时能绕过的战斗。主线过场与潮关原案另计。 [区域回归](regional-regions.log) · [潮关证据来源](regional-provenance.log)

选中地区任务后，追踪现在能指出去下一张地图的实际出口。复现时从凤溪西岸按 `J` 选择“水路证词”，客栈与雨巷入口都会出现 `支` 标记。进客栈问过船户后，标记转到外门，再从西岸指向雨巷。收齐证据而封渡尚未开始时，追踪等待条件开放。在潮关覆核中，标记也能从装卸渠指向已开启的仓阶，并在查秤与封绳后指向回渡口的第一段通路。 [凤溪原生运行](regional-network-native.log) · [西岸两条线索标记](fengxi-tracked-exits.png) · [客栈返程标记](fengxi-tracked-return.png) · [整线与潮关](regional-campaign.log)

Godot 用游戏实际碰撞规则校验了 250 个分阶段互动点位和 73 个显式落点，均能接入对应地图的可走区域。点位和落点数量用于核对几何覆盖；任务与地图数量在上表按地点去重。当前以脚本验证进度、操作与跨图连通，首次游玩总用时、无提示探索成功率及剧情复述仍待真人验证。 [几何日志](regional-geometry.log)
