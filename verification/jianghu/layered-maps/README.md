# 3.4.0 地图分层与场景功能验收

## 地图审视

3.3.1 有七个可回访区域。行路菜单直接列区域名，先知道目的地的人能迅速回去。首次往来时，聚落、野外和专用建筑的层级只散在对白与出口里。凤溪从渡口可直接跳到客栈或货巷，来往商旅经过的街面缺席。山庄道路大部分服务章节内通行。潮关的州府结案在渡口读到回执便停止，实际办理地点没有出现。 [3.3.1 实测基线](../full-campaign/REGIONS.md)

3.4.0 把中原与沿海州郡画成一张行路舆图，以凤溪水陆、西麓山道、北山关隘、沿海州郡归属现有七区。地区下能查看聚落、工区、野外驿路、宫院、遗迹和具体建筑。地图线路按剧情和已开启的接驳点更新，目录同时显示地标、邻接出口和当前可用的店铺或锻台。七区共有 26 个目录地点。凤溪复航前后的岸景是同一地点，区域碰撞检查覆盖 27 份实际场景。

| 层级 | 游戏中承担的行为 | 此次落实 |
| --- | --- | --- |
| 境域与地区 | 看政治地理、判断路接哪一区和何时能去。 | 舆图保留区域入口。实线和虚线按开通状态变化，水路与陆路另有色线。 |
| 聚落、码头与街巷 | 集散、买卖、雇工、核对去处。 | 西岸集市从原渡口石阶进入，有粥棚、粮行和去山路的东门。封渡期间可查秤，复航后可核对住户实际领粮结果。 |
| 野外与连接场景 | 转场有地理因果，主路和可选事件能并存。 | 集市与拜剑山庄之间新增石塘驿道。走主路可过境，也能沿北坡找车夫或在南岔交战。帮驿亭找回粮车后放下踏石，开启双向捷径。东岗未开放时由守人说明条件。 |
| 功能建筑 | 办事的人和设施分别承担任务、商店或后续安排。 | 丰义粮行让玩家亲自核对粮账与秤砣。州署外院有粮票案、会验廊和录事。潮关分案决定接下来发车还是错开证人到场时间，并开放不同返程。 |

主线保持原有起承和门槛。确认区名走安全入口，建筑和内部路线需要实地进入。新地点使用稳定的区域及事实键，旧档按原有剧情与回执开放。未完成的秤账、救援或州署安排要亲手推进。任务追踪以实际通行条件查找下一出口，经过两张以上地图时也可连续提示。

## 怎样玩到

1. 凤溪首度能回访后，按 `M` 打开舆图。手柄和触屏从暂歇菜单选择「查看江湖舆图」。选中区域后用 `Tab`、手柄 `X` 或点地名查看地点。确认前往该区域入口。
2. 西岸渡口从石阶进集市。店面中部进入丰义粮行，查粮袋和秤砣便可在封渡期复秤。集市东门随剧情开放后进石塘，沿东岗去山庄运铁道。
3. 潮关完成原案和「归灯分粮」回执以后，从粮仓东门进州署外院。公开案走东埠验收卸粮，交州府的案走渠北核对会验。两路在当地各有办事人和业务柜。州署与盐汊同一货源，换柜不会重复补货。
