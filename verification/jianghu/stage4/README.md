# 第四阶段交付验收 · 潮关归灯

## 进关和回访

1. 通关后，从尾声或标题进入「潮关余事」。也可从「江湖行路」选择潮关，或从重新开航的凤溪码头坐船过去。潮关保留盐汊渡口、装卸渠和粮仓三处原场景，三地允许往返。
2. 找陶伯推进原案。韩朔失守后，装卸渠东阶通往粮仓。拿回原账后，调查渠口批次、独立凭证、公秤和封绳，回渡口找徐掌簿。覆核完成后，从粮仓公秤旁可验盖印留档，往返渡口也可改用短泊舢板。
3. 原账交州府后，去粮仓对名册、封原账，经装卸渠把卷证和人证送到渡口，再取船章与受理回执。覆核印、外哨换岗或凌云山断后可以避开低滩残党。有敌情时可以败退重试。
4. 原账公开后，查渡口粮册，准备两户的粮，在渠上复称，送到两户并交副票，再去仓里查实发簿。凤溪保下的冬粮可就地备粮。两条后续各开一类货摊，阶段报酬进入潮关当地钱袋及材料库。

可在原案结案后补做覆核与归灯。3.2 旧档按原有结案走对应后续。此前错过阿芦的档案仍有新救援战，可以取回旧粮票。没有前期支线证词时，去装卸渠找免费凭单即可继续。
