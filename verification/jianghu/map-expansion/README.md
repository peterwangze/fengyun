# 3.5.0 山河驿路验收

[地图扩充设计](../../../MAP_EXPANSION.md)从主线阶段、地方势力、居民工作和任务交接推导各区域布局。3.5.0 在已有凤溪与潮关分层地图的基础上，新增 11 个可走场景，并将同样的设计落实到其余五区。地区目录共 37 个地点。38 份实际场景含不同剧情下同一地点的地图变体。

## 新区域与实际后续

- **天下会外哨**从旧岗院下岗下集，进出关簿房或沿白石沟通旧林道。公开药担副印启用东桥及行脚药柜，隐名护送启用沟底通路与岗下药棚。旧岗作证后可见乡亲点收。 [图形运行记录](watch-native.log) · [接管后的簿房](watch-dispatch-occupied-countermark.png) · [白石沟](watch-scree-covered.png)
- **无神绝宫**从外庭进苇津渡埠，向内进平秤公所，向东沿芦岸通西闸。公开案火后复秤分粮再开补给柜，封证案在芦棚接人并开双向暗扇。原火场主线证物和退路仍可独立完成。 [渡埠与火后两路](PALACE.md)
- **凌云山**从药炉山道下竹井坳。进避险屋查备用梁，上飞栈坡勘裂口。修栈能提前双向通撤离石阶；修屋得药柜，灯路开放后可走检修路。石阶的交接回单会注明实际去向。 [山民聚落与两条安置路](LINGYUN.md)
- **拜剑山庄与生死门**新增打炭匠里、松药坡。匠里的炭样和车牌交回剑庐才放行；救护期的黄绳药筐由药庐点收，开放断栈后坡并给原药柜补货。 [支路与回报检查](support-routes.log)
