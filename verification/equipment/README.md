# 2.2.0 行装与安装验收

| 验收项 | 结果与证据 |
| --- | --- |
| 境界与行装 | 验证境界二奖励、支线奖励、同一件行装转交、卸下、拒绝未取得的行装和旧存档迁移。验证削势、固守回气、对破势敌人的武学追击、受击减伤和治疗武学，以及手柄快捷键。[行装回归](equipment.log) |
| 标准主线 | 从新档跑完六章和潮关正门路线，全程未装备行装。终战合璧破盾，潮关救人后公开账簿。[标准流程](standard.log) |
| 支线与另一条主线 | 轻松难度跑完八条支线、全部十件行装的获取条件、渡船、北侧石栈与潮关水栅。终战以破势解盾。同一路线另跑一遍，在各章更换护具与佩物，验证整套装配可带入终战和外篇。[支线流程](quests.log) · [配装流程](equipped-route.log) |
| Android 安装与触屏 | Android 16 硬件加速模拟器从 2.1.1 覆盖安装，继续旧档。触屏给步惊云穿衣、转交给聂风、切换佩物、重启续档。聂风在战斗中显示装备后的 114 点气血。[转交预览](android-transfer-preview.png) · [重启后装配](android-reload.png) · [战斗属性](android-battle-gear.png) · [触屏回归](touch.log) |
| Windows 安装与键鼠 | Windows 11 x64 从 2.1.1 覆盖安装，核对开始菜单和可选桌面快捷方式。实际运行安装目录中的游戏，装备、卸下及后续章节回归。卸载保留存档。[行装界面](29-windows-equipment.png) · [安装记录](windows-install-result.json) |
