# 无神绝宫扩展场景来源

三张背景均使用内置 ImageGen 独立生成。提示指定固定三分之四俯视视角、16 位武侠像素画、冷青石墙和节制的暖灯，并预留可行走地面和人物位置。没有使用旧场景作为新地图的底图。

| 场景 | 提示的可交互构图 | 原画与游戏尺寸 |
| --- | --- | --- |
| 苇津渡埠 | 宫墙下的临水码头，左侧石拱门、沿街船户柜台、偏右公所正门、最东侧芦堤阶 | 2172 × 724，裁出纵向 13–710 行后缩至 560 × 180 |
| 芦岸巡径 | 古柳、芦苇、防汛石堤、短台阶、石砌凹室及通西闸的高阶，水面始终在石堤下方 | 2172 × 724，裁出纵向 106–636 行后缩至 736 × 180 |
| 平秤公所 | 称量台、粮袋、右侧文书案、帘布后的侧扇、底部正门 | 1672 × 941，裁出纵向 0–939 行后缩至 320 × 180 |

尺寸统一使用 Lanczos。交付图位于 `game/assets/field/` 的 `palace_quay.png`、`palace_reedpath.png`、`palace_storehouse.png`。同名 JSON 定义地面轮廓，入口和脚下点位贴合原画的拱门、台阶和石堤。
