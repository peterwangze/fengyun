# 天下会外哨场景原稿

3.5.0 使用内置 GPT 图像生成工具绘制岗下集、白石沟驿路和出关簿房。工具接口未提供可核验的模型版本。

| 原稿 | 游戏场景 | 提示词要点与原项目参考 |
| --- | --- | --- |
| [market.png](market.png) | `watch_gate_market` | 山脚驿市俯斜全景。三间木铺、浅灰石街、石阶，留出能步行与交谈的空地。参考天下会庭院和外哨；不绘人物、字样或界面。 |
| [scree.png](scree.png) | `watch_scree_road` | 长幅白石沟，斜俯视。西侧坡口、中央断木桥、东端岗门均沿一条步道串联，岩墙和沟渠退到路后。参考外哨林道；不绘人物、字样或界面。 |
| [dispatch.png](dispatch.png) | `watch_dispatch_house` | 驿道簿房。室内木梁、纸册与柜台分区，暖色照明，保留南门至簿案的宽阔地面。参考西岸客栈及潮关州署；不绘人物、字样或界面。 |

使用 Pillow 将驿市和簿房居中裁切至 320 × 180，将驿道直接调整至 768 × 180。三张图均用 Lanczos 缩放，锐度设为 1.15，再以中值切割量化至 168 色，关闭抖动。Godot 点采样显示，碰撞、落点和左右联通由 `game/assets/field/` 的对应 JSON 配置。
